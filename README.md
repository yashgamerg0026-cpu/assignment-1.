# Assignment 1: Layout & Alignment Basics

This repository contains a collection of exercises designed to practice and master fundamental CSS layout techniques, including alignment, Flexbox, and CSS Grid. The assignments progress from basic positioning concepts to more complex layouts and real-world UI replication.

## Project Structure

The exercises are organized into problem folders, with their corresponding solutions maintained in the `solutions` directory.

| Assignment | Description | Topic |
|---|---|---|
| `0-horizontal-align` | Practice horizontal alignment of elements | CSS Alignment |
| `1-vertical-align` | Practice vertical alignment of elements | CSS Alignment |
| `2-flex-layout` | Build layouts using Flexbox | Flexbox |
| `3-grid-layout` | Create layouts using CSS Grid | CSS Grid |
| `4-more-complicated-grid` | Implement more complex grid structures | Advanced CSS Grid |
| `5-vscode-bottombar` | Recreate the VS Code bottom status bar | UI Component 
## Learning Objectives

- **CSS Fundamentals:** Understand the box model, positioning, spacing, and element alignment.
- **Alignment:** Control horizontal and vertical positioning of elements.
- **Flexbox Mastery:** Build flexible, one-dimensional layouts using `display: flex`, `justify-content`, `align-items`, and `gap`.
- **CSS Grid:** Create structured, two-dimensional layouts using grid tracks, columns, rows, and gaps.
- **Advanced Layouts:** Combine layout techniques to build more complicated page structures.
- **UI Replication:** Translate existing interface designs into HTML and CSS.
- **Real-World Practice:** Develop practical frontend skills by recreating familiar interfaces such as Visual Studio Code.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Getting Started

### Prerequisites

You only need a modern web browser and a code editor such as Visual Studio Code.

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the assignment directory:

```bash
cd assignment-1
```

### Running the Exercises

Navigate to any problem folder to review the requirements and work on the exercise.

For example:

```bash
cd problems/0-horizontal-align
```

Or explore the Flexbox exercise:

```bash
cd problems/2-flex-layout
```

For the VS Code bottom bar exercise:

```bash
cd problems/5-vscode-bottombar
```
